Meta's Muse Agent Surpasses 500K Users Within First Week

Daily AI News Scan — Wednesday, September 23, 2026

Executive Summary

Meta's Muse agent crossed 500K users and 730,000 downloads in its first week, topping iOS App Store charts while a zero-day security flaw was simultaneously patched. Microsoft is reshaping Windows at the OS level to natively support AI agents with sandboxed execution and embedded local models. Meanwhile, OpenAI drew a pricing battle with Anthropic by releasing GPT-6 Sol and Luna at rates significantly below Claude Opus 5.5, accelerating a broader cost compression trend across frontier model providers.

Top Stories

1. Meta's Muse Agent Surpasses 500K Users Within First Week

Meta's Muse AI agent reached 500,000 total users and 250,000 daily active users within approximately one week of launch, while simultaneously climbing to the top of iOS App Store charts with 730,000 downloads. Muse is powered by Meta's Muse Spark AI models and is designed for task automation. The launch was not without friction: security researcher Patrick Wardle disclosed a zero-day vulnerability in the macOS version that allowed local attackers to hijack Muse accounts and access sensitive functions, which Meta patched shortly after disclosure. The rapid user growth also coincided with broader concerns about AI-generated content flooding platforms, with one creator publishing 445 ChatGPT-generated books on Amazon earning nearly $6,000, highlighting proliferation risks as agent-powered content tools scale.

Source: TechCrunch AI

2. Windows Integrating AI Agents at OS Level with Native Support

Microsoft is embedding AI agent infrastructure directly into Windows, introducing native agent identification via Entra ID, a centralized MCP server registry called the Windows On Device Agent Registry (ODR), and a new isolation technology called Microsoft Execution Containers (MXC). MXC is OS-agnostic and allows developers to run agentic tools in sandboxed environments with configurable containment policies, addressing growing concerns about agent security boundaries. Windows will also ship with embedded small language models (SLMs), enabling developers to run local inference without bundling models in their applications or relying on cloud APIs. The move positions Windows as a first-class platform for agentic software development, competing with macOS and Linux for developer mindshare in the emerging agent ecosystem.

Source: The Verge AI

3. OpenAI Launches GPT-6 Sol and Luna, Undercutting Anthropic's Claude Opus 5.5 Pricing

OpenAI released two new models under the GPT-6 family: Sol, priced at $2 input / $10 output per million tokens, and Luna, a lighter option at $0.10 input / $0.50 output per million tokens. The releases directly undercut Anthropic's Claude Opus 5.5, which is priced at $4 input / $20 output per million tokens, effectively triggering a price war between the two leading frontier labs. Anthropic had also recently reduced Claude Opus 5.5's token costs and cited competitive coding and agent benchmark performance. The pricing dynamic reflects accelerating commoditization pressure at the top of the model tier, with cost-per-token becoming a primary competitive lever alongside capability.

Source: MIT Technology Review AI
